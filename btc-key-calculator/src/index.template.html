Bitcoin Key Calculator

Private key → public key → addresses, and BIP32 hierarchical derivation. Runs entirely in this page.

Read this before you type a real key.
  • This page makes no network requests — its Content-Security-Policy is default-src 'none' — but a browser is still a poor place for a key that holds funds.
  • For anything real: save this file, disconnect the machine, then open it.
  • Keys generated here use crypto.getRandomValues. That is a proper CSPRNG, but a hardware wallet is still the better custodian.

What this calculates

  • Private key in hex, decimal and WIF (compressed and uncompressed, mainnet and testnet).
  • Public key as k·G on secp256k1, in compressed and uncompressed form, with the raw point coordinates and HASH160.
  • Addresses: P2PKH (BIP44), P2SH-P2WPKH (BIP49), P2WPKH (BIP84), P2TR (BIP86).
  • BIP32 master keys from a seed, extended key serialisation, hardened and normal child derivation, and watch-only derivation from an xpub.

What it deliberately does not do

It will not take an address and search for the private key that controls it. "Key hunting", puzzle scanners and brute-force range searches have no use except spending coins that belong to someone else, and against a 256-bit keyspace they do not work regardless.

How it is built

  • secp256k1 arithmetic in BigInt, affine coordinates.
  • SHA-256, SHA-512, HMAC-SHA512 from WebCrypto; RIPEMD-160 implemented directly, since WebCrypto omits it.
  • Base58Check, Bech32 and Bech32m written out, no dependencies.
  • Checked against BIP32 test vector 1, the BIP86 taproot vectors, the BIP173 segwit examples, the RIPEMD-160 reference vectors, and the long-standing key-of-1 addresses.
